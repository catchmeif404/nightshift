title: Add CSV export for items
---
Add `toCsv(items)` to a new file `src/csv.js` (named export) that turns an array of items into CSV text.

Requirements:
1. The first line is the header `sku,name,qty,price`; then one line per item in the same column order.
2. `price` is written with exactly two decimals (`0.5` -> `0.50`); `qty` is written as is.
3. A field that contains a comma, a double quote, a CR or an LF is wrapped in double quotes, and each double quote inside it is doubled (RFC 4180).
4. Lines end with `\n`, and the text ends with one trailing `\n` after the last line.
5. An empty array gives just the header line (with its trailing `\n`).
6. `toCsv` must not modify the array or its items.

Deliverable: `src/csv.js` plus tests in `test/csv.test.js`.
Check: `npm test` passes, including your new tests.
Out of scope: changing existing files, adding dependencies, a CLI command for it.
