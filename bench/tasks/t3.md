title: Low-stock report (library function and CLI command)
---
Add a low-stock report.

Requirements:
1. `lowStock(items, threshold = 5)` in `src/items.js` (named export) returns the items whose `qty` is less than or equal to `threshold`, sorted by `qty` ascending and then by `name` ascending (plain code-point string comparison). It returns a new array and does not modify its input.
2. `threshold` must be a non-negative integer; anything else (negative, fractional, NaN, a string) throws an `Error` with the message `invalid threshold`.
3. The CLI gets a command `low <file> [--threshold N]` in `src/cli.js`: it reads the JSON array from `<file>` and `run()` returns one line per low-stock item, formatted `<sku> <name> <qty>`, joined with `\n`. With no low-stock items it returns an empty string. `--threshold` takes the next argument as the number; a missing or invalid number throws `invalid threshold`. A missing `<file>` throws `usage: low <file> [--threshold N]`.
4. The existing `total` command keeps working unchanged.

Deliverable: the code plus tests (extend `test/items.test.js` and `test/cli.test.js`).
Check: `npm test` passes.
Out of scope: new dependencies, a new file for the feature, changing `totalValue`/`findByName`/`readItem`.
